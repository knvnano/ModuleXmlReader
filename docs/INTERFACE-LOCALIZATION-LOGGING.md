# Интерфейс 0.5.0, RU/EN, история изменений и log4net

## Интерфейс

Тёмная тема Fluent, единая палитра, карточки параметров и редакторов, вкладки
трёх таблиц и отдельная область холста. Существующее управление холстом сохранено:
колесо, средняя кнопка, Z, линейки, номера и пропуски.

Боковое меню содержит Редактор, Историю изменений, Журналы и О программе.
Кнопка меню переключает ширину 228/72 с анимацией 220 мс. Подписи плавно исчезают
и появляются за 160 мс. Активный раздел выделяется акцентом.
Переход между разделами не пересоздаёт редактор и не теряет правки документа.

## Мгновенный перевод

Кнопка RUS / ENG меняет язык в открытом приложении без перезапуска и перезагрузки
документа. Масштаб и смещение холста сохраняются.
Переводятся навигация, кнопки, вкладки, подсказки, статусы, ошибки валидации,
сообщения операций, подтверждение несохранённых изменений и окно About.
Уже открытые диалоги также подписаны на смену языка.

Ресурсы находятся в `ModuleXmlReader.Presentation/Localization/ru.json` и `en.json`.
Они встроены в сборку. TextCatalog уведомляет индексаторные привязки Avalonia
как Item и Item[]; это проверено UI-тестом, а не только заменой словаря.
Ошибки Application передают ключ сообщения и параметры через MessageToken:
показанная ошибка переводится повторно при смене языка.

XML-идентификаторы и значения файлов (имя, тип драйвера, коды) остаются данными
пользователя и не переводятся. Системные элементы нативного файлового диалога
используют язык операционной системы. Диагностические записи сохраняются в
исходном виде, включая текст исключений; язык UI не переписывает существующие логи.
Выбор языка действует для текущего запуска; сохранение настройки между запусками
в этот этап не включалось.

## История изменений

Источник — `ModuleXmlReader.Avalonia/changelog.json`. Файл копируется рядом с
приложением при сборке; приложение читает именно сохранённый файл рядом с executable.
Раздел перечитывает его при открытии и по кнопке Обновить. Существующие этапы
переноса, MVVM, исправлений, холста и текущего интерфейса уже внесены.

Чтобы добавить сохранённые изменения, добавьте элемент в массив:

```json
{
  "version": "0.5.1",
  "date": "2026-11-23",
  "titleRu": "Название изменения",
  "titleEn": "Change title",
  "itemsRu": ["Что изменилось"],
  "itemsEn": ["What changed"]
}
```

Формат массива проверяется при чтении. Ошибки показываются пользователю и
попадают в errors.log. Раздел не запрашивает внешние сервисы и не подменяет
историю изменений историей сохранения пользовательских модулей.

## Раздельные журналы

Используется log4net **3.6.0**, подключённый только к Infrastructure.
Внутренние слои работают через IAppLogger. При обычном запуске создаётся папка:

```text
%LOCALAPPDATA%\ModuleXmlReader\Logs\<UTC-дата-время>-<PID>\
  activity.log
  errors.log
  diagnostics.log
```

- activity.log — INFO/WARN: запуск и остановка, открытие/сохранение, повороты,
  переключение языка.
- errors.log — ERROR/FATAL: ошибки операций и необработанные исключения,
  с типом исключения, сообщением и стеком вызовов.
- diagnostics.log — DEBUG: валидация редактора, навигация и загрузка истории.

Файлы разделены фильтрами LevelRangeFilter. Размер одного файла — 2 МБ,
до трёх резервных копий на категорию. Отдельная папка на процесс исключает
конкурирующую ротацию нескольких запущенных экземпляров. Старые папки сеансов
автоматически не удаляются. Содержимое модулей целиком в журнал не записывается.

Раздел Журналы переключает категории и обновляет последнюю часть файла по кнопке.
Чтение ограничено 128 КБ и допускает совместную запись. Путь текущего сеанса
показан в интерфейсе. Записи можно выделять и копировать.

## Архитектура

- Domain: MessageToken, ChangeEntry и LogKind.
- Application: ключи ошибок, интерфейсы логирования/истории и журналирование
  успешно выполненных и пойманных ошибочных операций.
- Infrastructure: log4net, ограниченное чтение логов и JSON changelog.
- Presentation: TextCatalog, навигация, локализованные ViewModels.
- Avalonia: тема, анимация, Views, платформенные диалоги и обработка ошибок UI.

Документ и правила поворотов не менялись. Исходный WinForms-проект сохранён.
