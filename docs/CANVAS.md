# Сетка модуля: номера и управление холстом

- Точки трассы пронумерованы с 1 в порядке PointTableData; номера сохраняются при повороте. В пересечении с красной адресной линией остаётся её буква, как в NovaLCT; номер доступен в подсказке.
- Линейки сверху и слева показывают координаты с 1, остаются видимыми и синхронизируются с прокруткой. При малом масштабе часть подписей пропускается для читаемости.
- Колёсико приближает и отдаляет относительно курсора. При переполнении доступны обе полосы прокрутки без автоматического скрытия.
- Удержание средней кнопки перемещает холст; отпускание или потеря захвата завершает перемещение.
- Z и кнопка «Вписать» вписывают весь модуль в область просмотра. Z не перехватывает ввод в текстовых редакторах. В режиме вписывания масштаб обновляется при изменении размера области.
- Горизонтальный разделитель позволяет менять высоту области сетки; её ширина изменяется вместе с окном.
- Фиолетовые точки — пропуски. Пара 255-255 не содержит координат: положение восстанавливается только для единственной прямой трассы, подтверждаемой всеми известными точками. Это отмечено в подсказке. Для произвольной проводки номера пропусков показываются фиолетовым в списке «без координат»; вымышленные позиции не рисуются. Исходный XML при визуализации не изменяется.

MVVM и слои сохранены: подготовка номеров и данных пропусков — Application/Domain; рисование, линейки, масштаб и обработка указателя — Avalonia view.

Проверки: 81 тест; включая четыре угла, пропуски 1/17/33/49, неизвестные координаты, пиксельные цвета, нумерацию, колесо, среднюю кнопку, Z и изменение размера. Release-сборка без ошибок и предупреждений.
